# resume-builder（简历制作技能）

一个供 WorkBuddy / 类智能体使用的简历制作技能：按 **FAB 写作法**、**量化表达**、**强动词**、**ATS 规范**与 **JD 关键词对齐**，产出专业中文简历。

## 目录内容
- `SKILL.md`：触发词 + 7 步工作流
- `references/`：章节结构、写作指南、ATS 检查清单、技能关键词
- `assets/`：可填写的中文模板（`resume-template.md` / `cv-template.yaml`）

## 用法
将本目录整体放入 WorkBuddy 的 `skills/` 目录（用户级或项目级），对话中说
“帮我写简历 / 优化简历 / 程序员简历模板”即可触发。
