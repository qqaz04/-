# 技能关键词：从 JD 抽取并融入简历

## 为什么重要
很多公司的简历分选既有机器（ATS）也有不懂技术的 HR。若简历缺少 JD 中的高频技能词，很容易被机读阶段淘汰，或 HR 肉眼筛选时「对不上」。因此要**从目标岗位的 JD 中抽取高频关键词，融入技能清单与经历描述**。

## 方法
1. 收集 5–10 份同方向目标岗位的 JD。
2. 统计出现频率最高的技术词（工具、语言、框架、平台）。
3. 选 **5–10 个** 与自身匹配的词，写入「技能清单」，并在相关经历中自然出现。
4. 不堆砌、不造假：只写真正用过 / 能讲清的。

## 示例：Java 后端岗位 JD 高频词（按出现频次，源自 geekcompany/ResumeSample 统计）
> 括号为相对词频，越高越该优先覆盖。

java(730) · spring(305) · web(260) · mysql(250) · oracle(207) · linux(198) · j2ee(182) · javascript(177) · sql(176) · hibernate(169) · html(139) · tomcat(132) · struts(128) · jquery(116) · jsp(106) · ajax(96) · css(94) · ibatis(84) · mvc(77) · servlet(71) · xml(70) · mybatis(51) · redis(46) · apache(45) · python(38) · hadoop(37) · nosql(35) · mongodb(33) · svn(32) · maven(27) · nginx(26) · jdbc(24) · memcached(23) · jvm(21) · git(10) · json(27) · restful(5) · zookeeper(4) · solr(5) · netty(6) · hbase(6)

> 用法：若投递 Java 岗，技能清单至少覆盖 java / spring / mysql / redis / linux / mybatis / maven / git 等高频词，并确保工作经历中出现对应动词（如「用 Redis 做缓存」「用 Spring Cloud 做微服务」）。

## 通用高频技能词（跨岗位）
- 语言：Java / Python / Go / JavaScript / TypeScript / C++
- 前端：React / Vue / HTML / CSS
- 后端 / 数据：MySQL / PostgreSQL / Redis / Kafka / 微服务 / RESTful
- 云与运维：Docker / Kubernetes / AWS / Linux / CI-CD
- 工程实践：Git / 单元测试 / 自动化 / 性能优化

> 这些是「高频挡板词」：JD 提到而你确实用过，就一定要出现在简历里。
