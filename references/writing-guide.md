# 简历写作铁律：FAB + 量化 + 强动词

## 一、FAB 模型（源自 geekcompany/ResumeSample）

一份好的技术简历不光说明事实，更通过 FAB 增强说服力：
- **F（Feature）**：是什么——你做了什么。
- **A（Advantage）**：比别人好在哪些地方——你的方案 / 贡献独特在哪。
- **B（Benefit）**：如果雇佣你，招聘方会得到什么好处——你带来的业务价值。

写法技巧：提供**具体论据**，把论点留给阅读者自己得出；过分论证会显得自夸、引起反感，要「点到为止」。

### 范例（虚构示例，展示结构）
> 2006 年，我参与了手机 XX 网发布系统 WAPCMS 的开发（*大家都会写的部分*）。作为核心程序员，我不但完成了网站界面、调度队列的开发，更提出了高效的组件级缓存系统，通过碎片化缓冲有效提升了系统渲染效率（*很多人忘写：你具体负责的部分与贡献的价值*）。系统上线后，Web 前端性能从 10 QPS 提升到 200 QPS，服务器由 10 台减少到 3 台（*用量化数字增强可信度*）。2008 年我升任 WAPCMS 项目负责人，带领 3 人小组支持每天超过 2 亿的 PV（*这就是 Benefit：你能带给前雇主的价值，即你能带给新雇主的价值*）。

### 没有显赫成绩怎么办？
讲不出成绩时，**讲成长**：项目中遇到什么问题、别人怎么解决、你怎么解决、你的方案好在哪、最终效果如何。学习能力也是每家公司看重的。

## 二、量化原则

- **具体、量化、有说服力**是技术简历最需注重的地方。
- 优先用**前后对比数字**：性能 / 成本 / 效率 / 规模 / 用户量 / 收入的变化。
- 没有绝对数字，可用相对提升（提升 40%、下降 60%、缩短一半）。

## 三、强动词表（每条 bullet 以动作动词开头）

避免弱表达：「负责」「参与」「帮助」「处理」。用强动词 + 量化结果替代。

### 领导力 / 管理
Led（领导）· Directed（指导）· Managed（管理）· Supervised（监督）· Coordinated（协调）· Organized（组织）· Oversaw（监管）· Delegated（委派）· Mentored（指导培养）· Spearheaded（牵头）

### 成就 / 业绩
Achieved（达成）· Exceeded（超越）· Delivered（交付）· Surpassed（超出）· Accomplished（完成）· Implemented（落地实施）· Secured（赢得）· Increased（提升）· Drove（推动）

### 分析 / 解决问题
Resolved（解决）· Analyzed（分析）· Streamlined（精简）· Optimized（优化）· Improved（改进）· Evaluated（评估）· Investigated（排查）· Diagnosed（诊断）· Solved（解决）· Debugged（调试）

### 沟通 / 协作
Communicated（沟通）· Presented（汇报）· Collaborated（协作）· Negotiated（谈判）· Consulted（咨询）· Advocated（倡导）· Liaised（联络对接）

### 创新 / 主动性
Initiated（发起）· Designed（设计）· Developed（开发）· Created（创造）· Launched（启动）· Pioneered（开创）· Introduced（引入）· Formulated（ formulation）

### 技术岗高频强动词
Architected（架构设计）· Engineered（工程实现）· Deployed（部署）· Scaled（扩容）· Refactored（重构）· Automated（自动化）· Integrated（集成）· Configured（配置）· Built（构建）· Shipped（发布）

## 四、前后对照范例

| 弱（不要） | 强（要这样写） |
|---|---|
| Responsible for improving system performance | Optimized database queries, reducing load time by 40% |
| Helped the team launch a new product | Led a cross-functional team of 8 to launch the product, generating $2M in Q1 |
| 负责后端系统开发 | 主导订单服务重构，QPS 从 1k 提升至 5k，P99 延迟下降 60% |
| 参与了缓存优化 | 引入 Redis 多级缓存，缓存命中率从 72% 提升至 96%，数据库负载下降 45% |
| Managed a team of developers | Led a 5-person dev team to ship the SaaS platform, lifting customer acquisition by 25% |

### 使用要点
1. 每条 bullet 以强动词开头。
2. 动词 + 动作 + **量化结果**。
3. 同义词轮换，避免重复同一动词。
4. 动词与 JD 关键词对齐（见 `skill-keywords.md`）。
