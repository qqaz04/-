# ATS 通过率检查清单

ATS（Applicant Tracking System，简历分选系统）会在人看到简历前先机读。约 3/4 的简历在初筛阶段被静默淘汰，多数因格式或关键词问题。写完后逐项核对：

## 布局与格式
- [ ] **单栏布局**：优先单栏（top-down），避免双栏 / 多栏。双栏易被 ATS 读错顺序。
- [ ] **无照片**：不放置头像（美式规范，避免偏见；中文互联网岗可视情况，但默认不加）。
- [ ] **无 References 章节**：推荐人另行提供，不写进简历正文。
- [ ] **无表格 / 文本框 / 图片 / 图标**：这些 ATS 难以提取。用纯文本列表与分隔线。
- [ ] **标准字体**：用常见无衬线 / 衬线字体，避免艺术字体、特殊符号、emoji。
- [ ] **可纯文本提取**：导出的 PDF 文字可选中（非图片扫描件）。用 .docx 或文本型 PDF。

## 内容与关键词
- [ ] **章节标题标准化**：工作经历 / 教育背景 / 技能 等，避免自创标题。
- [ ] **关键词与 JD 对齐**：从目标岗位 JD 抽取 5–10 个高频技能词，融入技能清单与经历（见 `skill-keywords.md`）。
- [ ] **动词与 JD 同义**：JD 写「architect scalable solutions」，简历写「Architected」而非「responsible for」。
- [ ] **日期统一**：如 2022.03 – 至今，逆序排列。

## 自检方法（源自 OpenResume Parser 思路）
上传简历到 ATS 解析器类工具，看它提取出的姓名 / 职位 / 技能是否准确。若解析器拼错职位名或漏掉技能段，真实 ATS 也会一样出错——据此修正。

## 投递前最后的 3 个动作
1. 用纯文本打开简历，确认关键信息都能被复制选中。
2. 对照 JD 高亮匹配的关键词，缺口补入。
3. 单栏、无照片、无表格、无特殊符号。
